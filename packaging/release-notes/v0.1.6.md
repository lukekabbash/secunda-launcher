Secunda launches Windows Steam games I already own on Apple silicon. Steam handles sign-in and ownership. I never ask for a Steam password.

## 0.1.6

Secunda now updates itself. It checks once a day, and Secunda → Check for Updates… checks now. Every update is signed, and Secunda refuses one that isn't. If Steam or a game is running, Secunda asks before closing them to install.

Skyrim now has to open a real window before Secunda reports that it started. Earlier builds could say Skyrim was running after it had already closed or showed a black screen.

First Play is more forgiving on slower Macs. Steam gets three minutes to hand off a game instead of ninety seconds, and setup steps that used to wait forever now stop with an error.

If the Microsoft voice-audio download fails, Skyrim still starts. Dialogue is silent that session, and the next Play tries the download again.

Every launch now keeps a short record that never includes your account details, so a failed launch can be diagnosed from Settings → Diagnostics.

Black Ops II Zombies now starts. macOS was stopping the game when it opened the microphone for voice chat, because Secunda had never declared microphone use. The first time you play, macOS may ask whether Secunda Launcher can use the microphone. The window size is picked to suit your display.

This release is signed with an Apple Developer ID and notarized by Apple, so it opens without a security warning.

Games and Steam now appear under their own names in the Dock instead of "wine".

Secunda now cleans up after itself. Windows processes left behind by a session that ended badly are removed when Secunda opens and before each Play, and a setup step that times out no longer leaves background processes running. A live Steam or game session is never touched.

Vertical sync is off by default for Black Ops II, and the setting is available on its page.

Terms of Use and a Privacy Policy are linked from Settings → About.
