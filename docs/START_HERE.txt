SECUNDA — SOURCE-ONLY STEAM GAME LIBRARY FOR APPLE SILICON

This package includes Secunda and its free, source-built compatibility runtime.
It does not include Steam, any supported game, another player's account, game
files, saves, or a proprietary compatibility product.

YOU NEED
• An Apple-silicon Mac running macOS 15 or newer.
• Rosetta 2 (macOS can offer to install it when the Intel worker first runs).
• Your own Steam account and a legitimate copy of the game you want to run.
• Internet access and enough free space for Steam and your selected games.

SUPPORTED LIBRARY
• Skyrim Special Edition; Fallout 4.
• Supreme Commander; Forged Alliance; Supreme Commander 2.
• STAR WARS Battlefront II (Classic, 2005); Insurgency; Angels Fall First.
• Call of Duty: Black Ops II — Campaign, Multiplayer, and Zombies.

Skyrim Special Edition remains Secunda's proven end-to-end vertical slice.
Supreme Commander, Forged Alliance, Battlefront II Classic, Insurgency, and
Angels Fall First are newly catalogued profiles, not gameplay-test claims.

SETUP
1. Drag Secunda Launcher to Applications.
2. Open Secunda Launcher and choose Prepare Secunda.
3. Install Windows Steam through Secunda.
4. Sign in only inside Steam's own window.
5. Install a supported game in Steam, select it in Secunda, then choose Play.

PRIVACY AND CLEAN REMOVAL
Secunda keeps its Windows prefix, Steam session, game installations, saves,
backups, caches, and logs under:
~/Library/Application Support/Secunda Launcher

The DMG contains none of that personal data. Removing the app does not remove
that folder automatically; archive any saves you want before deleting it.

OPEN-SOURCE MATERIALS
The Sources folder contains the corresponding source archive, Secunda's Wine
patches and build scripts, component notices, checksums, and an SPDX SBOM.

MACOS SECURITY
An ad-hoc-signed test build can show an extra first-open warning. A release
signed and notarized by its publisher avoids that warning. Never disable macOS
security to run Secunda.
